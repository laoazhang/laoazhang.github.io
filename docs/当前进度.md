## 已知限制

1. 本地环境：系统 Ruby 2.6，Jekyll 4.3 依赖需 Ruby ≥2.7/3.1，无法用 bundler 安装。
   当前用「curl 下 gem + 本地安装 + `JEKYLL_NO_BUNDLER_REQUIRE=true`」跑通构建。
   长期建议装 Ruby 3.x（rbenv/brew）后用 `bundle install`。
2. `Gemfile.lock` 原本就不一致（`google-protobuf 3.25.2` vs sass-embedded 要求 `~>3.25.5`，
   `http_parser.rb ~>0.6` vs 锁定 0.8.0），未彻底修。
3. `npm run assets` 用 lessc+clean-css 重新编译，结果**语义等价但非字节一致**：
   - 等价规范化：`bold`→`700`、`#c0c0c0`→`silver`、`.5em`
   - 真实差异：IE hack（`zoom:1`、`outline:thin dotted \9`、checkbox 尺寸）被丢弃
   - 因此**不要随手覆盖冻结产物**；真要改样式，先截图比对再替换
4. `assets/less/**` 源码会被 Jekyll 发布到线上（历史行为，未改）。

## 常用命令

```bash
# 本机构建（当前环境）
export PATH="$HOME/.gem/ruby/2.6.0/bin:$PATH"
export JEKYLL_NO_BUNDLER_REQUIRE=true
jekyll build            # 输出 _site

# 资源（仅在改 LESS/JS 时用）
npm install
npm run assets          # lessc + terser，注意会覆盖冻结产物

# 基线对比

diff -rq _site_base _site_new
```
